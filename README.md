# SWYNEX-Interactive-Dashboard
1. KPI Card
Metric: Sum of Purchase Amount (₹)
Purpose: Displays total purchase value (e.g., ₹3M).
Concepts Used: DAX measure, KPI visualization, conditional formatting.

2. Slicers
Filters:
Festival/Sale (Amazon, Big Billion Days, Diwali, etc.)
Online Store (Ajio, Amazon, Flipkart, etc.)
Brand (Levis, Nike, Zara, etc.)
Location
Purpose: Enables dynamic filtering and cross-interaction between visuals.

3. Pie Charts
Online vs Offline Sales
Gender Distribution
Payment Method Breakdown
Generation Count
Delivery Speed Comparison
Concepts Used: Category segmentation, percentage visualization.

4. Bar Chart
Metric: Sum of Purchase Amount by Online Store
Purpose: Compares store-wise performance.
Concepts Used: Aggregation, sorting, data labels.

5. Treemap
Metric: Orders by Location
Purpose: Visualizes regional order distribution.
Concepts Used: Hierarchical data representation.

6. Category Buttons
Categories: Accessories, Footwear, Clothing
Purpose: Interactive navigation between product categories.
Concepts Used: Bookmarks, button actions.

7. Trend Chart
Metric: Sum of Purchase Amount by Year
Purpose: Shows year-over-year sales trend.
Concepts Used: Time-series analysis, DAX measure.
